Loss of SCADA communications

  1. Confirm local HMI / panel operation and record the time of loss.
  2. Check ring status LEDs on switches (MRP manager, RM / RING indicators).
  3. Check the PLC CPU state: RUN, STOP, and redundancy sync (REDF / IFM LEDs on an S7-400H).
  4. Verify the primary and standby server heartbeat links.
  5. Switch affected plant to local or manual control per the site procedure; log every action.

Redundant PLC switchover

  1. Confirm the standby CPU is in SYNCUP then RUN (redundant) before any maintenance.
  2. Do not stop both CPUs; stop only the CPU being serviced.
  3. After restart, confirm the sync module link and compare program versions.

Network fault isolation

  1. Ping the gateway and PLC addresses from the engineering station.
  2. Check fiber link light levels and connector cleanliness on the failed segment.
  3. Confirm the ring has reconfigured (the ring manager should show an open ring, not a blocked port, after a single break).
